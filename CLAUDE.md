# CAIRRL Lab Website Assistant Instructions

Before answering or performing any work in this codebase, you must review the core documentation files in the repository root:

- **`Rules.md`**: Tech stack lock-in, coding conventions, no content fabrication, auth & security rules.
- **`PRD.md`**: Product requirements, IA, and the official Seed Roster (`PRD.md §13`).
- **`Phases.md`**: Sequential development phases.
- **`Memory.md`**: Current snapshot, completed work log, and decisions log. (Update at the end of each session!)
- **`Design.md`**: Design tokens, typography (Space Grotesk, Inter, JetBrains Mono), colors, component rules.
- **`Architecture.md`**: App Router architecture, Prisma schema, rendering strategies.

## Essential Commands
- Start dev server: `npm run dev`
- Production build: `npm run build`
- Linter: `npm run lint`
