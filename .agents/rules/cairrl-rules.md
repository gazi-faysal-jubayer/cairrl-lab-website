# CAIRRL Lab Project Rules

All agents operating in this workspace must respect the project documentation:

1. **`Rules.md`**: Tech stack lock-in, coding conventions, no content fabrication, auth & security rules.
2. **`PRD.md`**: Product requirements, IA, and the official Seed Roster (`PRD.md §13`).
3. **`Phases.md`**: Sequential development phases.
4. **`Memory.md`**: Current snapshot, completed work log, and decisions log. (Update at the end of each session!)
5. **`Design.md`**: Design tokens, typography (Space Grotesk, Inter, JetBrains Mono), colors, component rules.
6. **`Architecture.md`**: App Router architecture, Prisma schema, rendering strategies.
